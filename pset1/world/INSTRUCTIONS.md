## Your task

Create hello.c and write a C program that prints hello, world followed by a newline. This is a practice exercise; no submission is required.

## Open and edit

In VS Code's container Bash terminal:

```bash
cd /workspaces/cs50x/pset1/world
code hello.c
```

Save changes with Ctrl+S. Create a source file if it is not provided; existing
starter files and datasets are already downloaded.

## Run and check

```bash
make hello
./hello
style50-cli hello.c
```

Compile successfully, run the executable, and compare its output with the official example.

After manual testing, run the official checks locally:

```bash
check50 --local cs50/problems/2026/x/world
```
