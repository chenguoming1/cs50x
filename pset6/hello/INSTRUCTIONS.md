# Hello, Again

[Complete official specification](https://cs50.harvard.edu/x/psets/6/hello/)
| [Problem Set 6 guide](../README.md)

## Your task

Create `hello.py`. Ask the user for their name, then print a greeting containing
that name. For input `David`, the greeting should be `hello, David`.
Use Python for this version of the problem.

## Open and edit

Run these in VS Code's container terminal:

```bash
cd /workspaces/cs50x/pset6/hello
code hello.py
```

Write your program and save with Ctrl+S.

## Run and check

```bash
python hello.py
style50-cli hello.py
check50 --local cs50/problems/2026/x/sentimental/hello
```

Test manually with several different names before running check50.

## Submit when ready

```bash
submit50 cs50/problems/2026/x/sentimental/hello
```
