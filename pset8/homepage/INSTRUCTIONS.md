## Your task

Build at least four linked HTML pages, including index.html, with navigation between all pages. Use at least ten distinct HTML tags beyond html, head, body, and title; a Bootstrap feature; a styles.css file with at least five selectors and five CSS properties; and JavaScript interactivity. Make the site work on mobile and desktop. Create specification.txt listing your tags and CSS properties and briefly describing the JavaScript and Bootstrap features.

## Open and edit

In VS Code's container Bash terminal:

```bash
cd /workspaces/cs50x/pset8/homepage
code index.html styles.css
```

Save changes with Ctrl+S. Create a source file if it is not provided; existing
starter files and datasets are already downloaded.

## Run and check

```bash
http-server
```

In VS Code's **Ports** panel, open port **8080** in your browser.
Keep the server terminal running while testing. Use Ctrl+C to stop it before
typing other commands, or open a second terminal. Stop the previous problem's
server before starting another one on the same port.

Test all links and interactions at several screen sizes. Validate the HTML with the service linked in the specification. There is no check50 for this assignment.
