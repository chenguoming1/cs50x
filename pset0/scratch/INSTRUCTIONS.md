# Starting from Scratch

[Complete official specification](https://cs50.harvard.edu/x/psets/0/scratch/)
| [Problem Set 0 guide](../README.md)

Requirements and course commands checked on 25 October 2026. Read the full
specification for demonstrations, all edge cases, and permitted edits.

## Your task

Build an interactive story, animation, game, or other project in Scratch. Include at least two sprites (one must not be a cat), three scripts in total, a conditional, a loop, a variable, and a custom block with at least one input. Aim for a project more substantial than the smallest lecture demonstrations. Credit any imported media in comments.

## Create and save

1. Open [Scratch](https://scratch.mit.edu/) in your browser and choose Create.
2. Build and test your project in the Scratch editor.
3. Choose **File > Save to your computer** to export an `.sb3` project.
4. Save the file in this workspace's `pset0/scratch` folder.

Scratch uses its own editor; you do not compile or run it in the container.

## Check your work

Try every interaction and check each requirement before exporting. Keep the project under 10 MB so the course checker can process it reliably.

## Submit when ready

Complete the preliminary account setup linked from the official specification.
Then sign in and upload the exported `.sb3` at the
[official Scratch submission page](https://submit.cs50.io/upload/cs50/problems/2026/x/scratch).
Use that page to upload the file and inspect the resulting checks yourself.
